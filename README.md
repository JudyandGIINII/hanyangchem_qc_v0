1. OCR/LLM은 추출 후보만 만든다.
2. 최종 판정은 Decimal 기반 결정론적 엔진과 사람 승인으로만 확정한다.

4. 검사 생성 당시 기준 버전과 승인 Snapshot을 불변 보존한다.
